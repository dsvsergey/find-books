# findbooks — вибір мови інтерфейсу (EN/UK)

Дата: 2026-09-29. Доповнює `2026-09-29-findbooks-design.md` і `2026-09-29-findbooks-libraries-screen-design.md`.

## Мета

Зараз усі тексти для користувача — українською. Потрібна англійська мова (за замовчуванням) і можливість перемкнути інтерфейс на українську: збереженим налаштуванням, разово з командного рядка і прямо в TUI. README — англійською, український варіант зберігається.

**Критерій успіху:**
- на чистій машині `findbooks search x` (порожній індекс) друкує англійську підказку;
- `findbooks config lang uk` → наступні запуски українською; `findbooks --lang en list` — разово англійською;
- у TUI `ctrl+g` миттєво перемикає мову всього екрана і запам'ятовує вибір;
- `README.md` англійською, `README.uk.md` українською, з посиланнями одне на одне.

## Рішення

| Питання | Рішення |
|---|---|
| Механізм перекладів | Власний пакет `internal/i18n`: ключі-константи, словник на мову, `T(key, args...)` |
| Мови | `en` (за замовчуванням), `uk` |
| Збереження | `DataDir()/config.json`, пакет `internal/config` |
| Пріоритет | `--lang` > `FINDBOOKS_LANG` > `config.json` > `en` |
| Перемикання в TUI | `ctrl+g` на будь-якому екрані: `en ↔ uk`, збереження в конфіг |
| Тексти Cobra | наші описи команд/прапорців перекладаються; вбудовані «Usage:/Flags:» Cobra лишаються англійською |

## Компоненти

### i18n

```go
type Lang string
const (EN Lang = "en"; UK Lang = "uk")
var Langs = []Lang{EN, UK}

type Key int // одна константа на кожен текст для користувача

func Parse(s string) (Lang, error) // "en"/"uk" (без урахування регістру, пробіли обрізаються); інакше помилка «unknown language "xx" (available: en, uk)» — завжди англійською
func Set(l Lang)                   // атомарно
func Current() Lang
func T(k Key, args ...any) string  // fmt.Sprintf(шаблон поточної мови, args...); без args — шаблон як є
```

- Каталог — `map[Lang]map[Key]string` у коді (без файлів).
- Пакет не імпортує жодного іншого пакета проєкту (лист графа залежностей), тож його можуть використовувати всі.
- Тест повноти: кожен `Key` від першого до останнього має непорожній шаблон в обох мовах, і послідовності форматних дієслів (`%d`, `%s`, `%q`, `%v`, `%w` не використовується) у двох мовах однакові.
- Помилки з `%w` не будуються через `T`: пакети, що обгортають помилки, роблять `fmt.Errorf("%s: %w", i18n.T(key, ...), err)` або `fmt.Errorf("%w: %s", sentinel, ...)`, щоб `errors.Is` працював.

### config

```go
type Config struct { Lang string `json:"lang,omitempty"` }
func Load() (Config, error)   // DataDir()/config.json; відсутній → Config{}, nil; зіпсований → Config{}, nil
func Save(c Config) error     // атомарний запис (temp + rename)
```

### Вибір мови (cli)

- `cli.Execute` визначає мову **до** побудови дерева команд (описи команд залежать від мови):
  1. `--lang X` або `--lang=X` серед аргументів (попередній розбір `os.Args`, без Cobra);
  2. інакше змінна `FINDBOOKS_LANG`;
  3. інакше `config.Load().Lang`;
  4. інакше `en`.
- Хибне значення з будь-якого джерела → повідомлення `i18n.Parse` у stderr, код виходу 2.
- `--lang` також оголошений як persistent-прапорець, щоб Cobra його приймав і показував у довідці.

### CLI

- Нова команда `findbooks config lang [en|uk]`: без аргументу друкує поточну мову (з позначкою джерела не потрібно — лише код мови); з аргументом — перевіряє, зберігає в конфіг, друкує підтвердження мовою, яку щойно встановлено.
- Усі наші тексти (описи команд і прапорців, заголовки таблиць, звіт сканування, помилки, підказки, «перервано», повідомлення про кількість аргументів) — через `i18n.T`.

### Глибші пакети

- `index` (ErrNotFound, ErrExists, помилка версії схеми), `library` (Locate), `libman` (ErrOffline, диск не знайдено), `scan` («тека бібліотеки недоступна») і `cli`-підказки — усі тексти для користувача через `i18n`.
- Сентинели лишаються змінними для `errors.Is`, з технічним англійським текстом (`errors.New("library not found")`).
- Для користувацьких помилок пакет `i18n` надає:
  ```go
  func Errorf(sentinel error, k Key, args ...any) error
  ```
  Повертає помилку, у якої `Error()` — лише локалізований текст `T(k, args...)` (без технічного хвоста), а `Unwrap()` — `sentinel` (може бути `nil`). Текст обчислюється в момент створення помилки, поточною мовою.
- Пакети повертають `i18n.Errorf(ErrNotFound, KeyLibraryNotFound, name)` тощо; CLI і TUI друкують `err.Error()` як є. Обгортання іншої причини: `fmt.Errorf("%s: %w", i18n.T(k, ...), cause)`.

### TUI

- `ctrl+g` на екрані пошуку і на екрані бібліотек (крім станів choosing/removing/job — там ігнорується, як інші клавіші): `i18n.Set(інша мова)`, перемальовування, асинхронне збереження `config.Save` у `tea.Cmd`; помилка збереження → статус.
- Усі тексти екранів (підказки клавіш, заголовки, мітки деталей, статуси, плейсхолдер поля пошуку) — через `i18n.T` під час рендеру, тож перемикання діє миттєво. Статус, що вже показаний, лишається мовою, якою створений.
- Підказки клавіш містять `ctrl+g EN/УКР` (поточна мова виділена або показана як `ctrl+g → УКР` / `ctrl+g → EN`).
- Діалог Finder: prompt береться з `i18n.T` у момент відкриття.

### README

- `README.md` — англійською (основний), `README.uk.md` — поточний український текст, оновлений розділом про мову.
- Угорі кожного: `English | [Українська](README.uk.md)` і `[English](README.md) | Українська`.
- Обидва документують `--lang`, `FINDBOOKS_LANG`, `findbooks config lang`, `ctrl+g`.

## Тестування

- `i18n`: `Parse` (регістр, пробіли, хибне), `T` з аргументами, повнота каталогу і відповідність форматних дієслів, `Errorf` (`errors.Is` + текст без хвоста).
- `config`: Load відсутнього/зіпсованого, Save+Load, атомарність (тимчасовий файл не лишається).
- `cli`: пріоритет джерел мови (прапорець > змінна > конфіг > en); хибна мова → код 2; `config lang` показ і збереження; англійська за замовчуванням (`search` на порожньому індексі — англійська підказка); наявні тести, що перевіряють українські рядки, встановлюють `uk` (прапорцем або `i18n.Set` у `TestMain`) — їхні очікування не змінюються.
- `tui`: `ctrl+g` перемикає мову (вигляд змінюється, викликається збереження через ін'єктовану дію), ігнорується під час choosing/removing/job; наявні тести отримують `i18n.Set(UK)` у `TestMain`.
- Тести ніколи не пишуть поза тимчасовими теками (`XDG_DATA_HOME` у `TestMain`), не чіпають `/Volumes` і `~/.local/share`.
