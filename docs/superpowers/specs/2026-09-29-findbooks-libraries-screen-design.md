# findbooks — екран «Бібліотеки» в TUI

Дата: 2026-09-29. Доповнює `2026-09-29-findbooks-design.md`.

## Мета

Зараз першим кроком користувач мусить знати CLI-команду `findbooks add <шлях>`: `findbooks` на порожньому індексі завершується помилкою. Мета — керувати бібліотеками прямо з TUI: вибрати теку системним діалогом, побачити прогрес індексації, оновити чи прибрати бібліотеку.

**Критерій успіху:** на чистій машині `findbooks` відкриває екран «Бібліотеки»; `a` → діалог Finder → вибір `/Volumes/dsvDev/Бібліотека/Советская фантастика` → прогрес-бар → бібліотека у списку; `esc` → пошук «чужие дети» працює.

## Рішення

| Питання | Рішення |
|---|---|
| Вибір теки | Системний діалог macOS (`osascript … choose folder`) через `platform.ChooseFolder`; Windows/Linux — `ErrUnsupported` |
| Обсяг | Повний екран: список, додати (`a`), оновити (`u`), прибрати (`d` з підтвердженням) |
| Спільна логіка | Новий пакет `internal/libman`; CLI `add`/`update` переходять на нього |
| Порожній індекс | `findbooks` відкриває TUI на екрані «Бібліотеки» замість помилки |

## Компоненти

### platform

```go
var ErrCanceled = errors.New("platform: canceled by user")
func ChooseFolder(prompt string) (string, error) // абсолютний шлях теки
```

- darwin: `osascript -e 'POSIX path of (choose folder with prompt "<prompt>")'`; stdout без кінцевого `\n` і кінцевого `/` (крім `/`). Скасування (stderr містить `-128`, код виходу 1) → `ErrCanceled`. Інші помилки обгортаються.
- prompt передається як окремий аргумент AppleScript (`on run argv`), щоб лапки в тексті не ламали скрипт.
- windows/linux: `"", ErrUnsupported`.

### libman

```go
type Progress = scan.Progress
func Add(ctx context.Context, st *index.Store, dir, name string, onProgress func(Progress)) (index.Library, scan.Report, error)
func Update(ctx context.Context, st *index.Store, lib index.Library, onProgress func(Progress)) (scan.Report, error)
var ErrOffline // диск бібліотеки не підключено
```

- `Add`: `library.Locate` → `library.Root` → назва за замовчуванням `filepath.Base(root)` → `st.AddLibrary` → `scan.Run`. Якщо сканування впало після реєстрації — повертає зареєстровану `Library` разом з помилкою (виклик вирішує, як підказати «продовжити через update»).
- `Update`: `library.Root` (не підключено → `ErrOffline` з назвою диска) → `scan.Run`.
- CLI `add`/`update` використовують `libman`; їхній вивід і підказки не змінюються.

### TUI

- Модель має два екрани: `screenSearch` (як зараз) і `screenLibraries`.
- Старт: якщо в індексі немає бібліотек — `screenLibraries`, інакше `screenSearch`. `findbooks` більше не повертає `errNoLibraries` на порожньому індексі; `search` і далі повертає.
- Перемикання: `ctrl+l` з пошуку → бібліотеки; `esc` з бібліотек → пошук (якщо індекс порожній — `esc` виходить з програми).
- Екран «Бібліотеки»:
  - список `st.Libraries()`: назва, диск ●/○ (перевірка підключення — асинхронно), книг, творів, дата оновлення; ↑/↓ вибір;
  - порожній список — підказка «Натисніть a, щоб додати бібліотеку»;
  - `a`: `ChooseFolder("Виберіть теку бібліотеки")` у `tea.Cmd`; скасування — без повідомлення; `ErrUnsupported` — «Діалог недоступний — використайте findbooks add <шлях>»; далі `libman.Add` у фоні;
  - `u`: `libman.Update` для вибраної; `ErrOffline` → «Диск «X» не підключено»;
  - `d`: рядок підтвердження «Прибрати «X» з індексу? Файли не чіпаються. (y/n)»; `y` → `st.RemoveLibrary`, будь-яка інша клавіша — скасування;
  - під час індексації: прогрес-бар (bubbles `progress`) і «N/M»; `esc` скасовує через `context.CancelFunc`; інші клавіші ігноруються;
  - після завершення — рядок звіту («Додано: …, оновлено: …, видалено: …, без змін: …; проблемних файлів: K»), оновлення списку і загальної кількості творів для екрана пошуку;
  - скасування чи помилка першого сканування → «Бібліотеку «X» зареєстровано, індексацію перервано — натисніть u, щоб продовжити».
- Прогрес передається з горутини сканування через канал; `tea.Cmd`-«слухач» читає наступне повідомлення (стандартний патерн Bubble Tea). Канал закривається після фінального повідомлення.
- Бекенд TUI — інтерфейс (пошук, `BookWorks`, `Libraries`, `TotalWorks`, `RemoveLibrary`, `Add`, `Update`, `ChooseFolder`), щоб модель тестувалась з фейками; `*index.Store` + `libman` + `platform` поєднуються в `tui.Run`.
- Підказки клавіш внизу екрана відповідають активному екрану. На екрані пошуку додається `ctrl+l бібліотеки`.

## Обробка помилок

- Повторна назва чи шлях → «Бібліотека «X» уже є» (з `index.ErrExists`).
- Тека не на підключеному томі / не тека → текст помилки `library.Locate`.
- Помилка БД під час видалення → рядок статусу.
- Жодна операція екрана не блокує UI-потік: діалог, сканування, перевірка підключення — у `tea.Cmd`.

## Тестування

- `libman`: Add (успіх, повтор назви, помилка сканування після реєстрації повертає Library), Update (успіх, офлайн → `ErrOffline`) — на тимчасових теках і БД (з `XDG_DATA_HOME` у тимчасовій теці).
- `platform`: розбір виводу `osascript` (кінцевий `\n`, `/`, скасування `-128`) — через ін'єкцію виконавця команди; сам діалог — ручна перевірка.
- `tui`: з фейковим бекендом — порожній індекс відкриває бібліотеки; `ctrl+l`/`esc` перемикання; `a` → вибір → прогрес → готово → список оновлено і total оновлено; скасування діалогу; `ErrUnsupported`; `esc` під час індексації викликає cancel; `d` + `y` видаляє, `d` + інша клавіша — ні; `u` офлайн.
- `cli`: наявні тести проходять; `findbooks` на порожньому індексі викликає TUI (заміна `runTUI`), а не повертає помилку.
- Ручна перевірка користувачем: діалог Finder, прогрес, повний сценарій критерію успіху.

## Поза межами

Перейменування бібліотек, вибір кількох тек за раз, навігатор тек усередині TUI, діалоги для Windows/Linux.
