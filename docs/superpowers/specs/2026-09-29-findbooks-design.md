# findbooks — дизайн

Дата: 2026-09-29

## Мета

Бібліотеки електронних книг лежать на кількох зовнішніх дисках (напр. `/Volumes/dsvDev/Бібліотека/Советская фантастика`: ~11.5k файлів, 5.9 ГБ, з них 10 826 FB2). Частина книг — збірки/антології/альманахи, і щоб знайти, де надруковано конкретний роман, повість чи оповідання, доводиться відкривати файли вручну.

`findbooks` — CLI на Go, що один раз індексує бібліотеки і дає миттєвий пошук твору за назвою/автором, показуючи, в якій книзі (збірці), на якому диску і в якому файлі він лежить.

**Критерій успіху:** запит «чужие дети» за <100 мс повертає «Румбы фантастики. 1988 год. Том II → Игорь Пидоренко → ЧУЖИЕ ДЕТИ» з шляхом до файлу — навіть коли диск не підключено.

## Рішення

| Питання | Рішення |
|---|---|
| Інтерфейс | Cobra-команди + інтерактивний TUI (Bubble Tea / Bubbles / Lip Gloss), що запускається без аргументів |
| Індекс | Один глобальний SQLite-файл `~/.local/share/findbooks/index.db` |
| Рушій пошуку | SQLite FTS5 через `modernc.org/sqlite` (чистий Go, без cgo) + fuzzy-ранжування кандидатів у TUI |
| Офлайн-диски | Пошук працює завжди; результат позначає диск як online/offline |
| Що індексуємо | FB2 (у т.ч. `.fb2.zip`) — метадані + твори з дерева секцій; PDF/DJVU/DOC/RTF/TXT — лише ім'я файлу та тека |

## Архітектура

```
cmd/findbooks/        main.go: Cobra root (без аргументів → TUI)
internal/library/     реєстр бібліотек: шлях, мітка диска (Volume UUID + назва)
internal/scan/        обхід тек, інкрементальність (розмір + mtime), пул воркерів
internal/fb2/         потоковий парсер FB2: title-info + дерево секцій;
                      windows-1251/koi8-r → UTF-8; .fb2.zip
internal/extract/     вибір «творів» із дерева секцій (евристика)
internal/index/       SQLite: схема, запис, FTS5-запити, нормалізація тексту
internal/tui/         Bubble Tea: поле вводу, список результатів, панель деталей
```

Залежності між пакетами односпрямовані: `cmd → tui, scan, index, library`; `scan → fb2, extract, index`; `extract → fb2`. `fb2` і `index` нічого не знають один про одного.

### Модель даних

- `libraries(id, name, root_rel, volume_uuid, volume_name, last_scan_at)` — `root_rel` — шлях відносно точки монтування тому; повний шлях відновлюється через пошук змонтованого тому за UUID (`diskutil info`), тож зміна точки монтування не ламає індекс.
- `books(id, library_id, rel_path, format, size, mtime, title, authors, year, is_collection)`
- `works(id, book_id, title, author, tree_path)` — `tree_path`, напр. `Игорь Пидоренко › ЧУЖИЕ ДЕТИ`.
- `works_fts` — FTS5 (external content над `works`) з нормалізованими `title`, `author`, `book_title`.

Для книги, що не є збіркою, у `works` записується один рядок — сама книга (назва з `book-title`, автори з `title-info`). Для не-FB2 — один рядок з назвою, виведеною з імені файлу.

### Нормалізація тексту

Застосовується однаково при індексації та запиті: нижній регістр, `ё→е`, прибирання лапок `«»„“"'`, пунктуації та повторних пробілів. Запит розбивається на слова, кожне шукається як префікс (`слово*`), слова поєднуються через AND.

### Евристика вибору творів (FB2)

Обхід секцій основного `<body>` (не `notes`):

1. **Шумові заголовки ігноруються** (як твори), але їхні діти обходяться: чисто числові/римські (`1`, `IV`), `Глава N`, `Часть N`, `Пролог`, `Эпилог`, `Примечания`, `Содержание`, `Оглавление`, `От составителя`, `Предисловие`, `Послесловие`, `Об авторах…`, `Библиография…`.
2. **Секція-автор:** заголовок, що збігається (після нормалізації, за прізвищем + ім'ям) з одним з авторів `title-info`, стає контекстом-автором для вкладених секцій і сам твором не є.
3. **Твір** — перша нешумова секція з заголовком на шляху від кореня (або від секції-автора); її внутрішні підсекції як твори не індексуються.
4. **Збірка** — книга, у якої знайдено ≥2 твори. Якщо знайдено 0–1 — книга індексується як звичайна (один рядок = сама книга).
5. Автор твору: контекст-автор, інакше — якщо у `title-info` рівно один автор — він, інакше порожньо.

### Сканування

- `scan` обходить теку бібліотеки, для кожного файлу порівнює `(rel_path, size, mtime)` з `books`; незмінені пропускає, змінені/нові парсить у пулі воркерів (N = кількість CPU), записує пакетами в одній транзакції; зниклі файли видаляє з індексу.
- Биті файли не зупиняють скан — збираються у звіт, що друкується в кінці.
- Прогрес-бар (Bubbles `progress`) у терміналі.

## Команди

```
findbooks                         → інтерактивний TUI
findbooks add <шлях> [--name X]   → зареєструвати бібліотеку і проіндексувати
findbooks update [назва|--all]    → переіндексувати змінене (лише підключені диски)
findbooks list                    → бібліотеки: к-сть книг/творів, online/offline, дата скану
findbooks remove <назва>          → прибрати бібліотеку з індексу
findbooks search <запит> [--author X] [--limit N] [--json]
```

`--name` за замовчуванням — ім'я теки бібліотеки. `search` друкує таблицю «Твір · Автор · Книга · Бібліотека/шлях»; `--json` — масив об'єктів для скриптів.

## TUI

```
┌ 🔎 чужие дети_                                    3 з 128 412 ┐
│ ▸ Чужие дети — Игорь Пидоренко                                │
│     в: Румбы фантастики. 1988 год. Том II  [dsvDev ●]         │
│   …                                                           │
├───────────────────────────────────────────────────────────────┤
│ Книга:  Румбы фантастики. 1988 год. Том II (1988)             │
│ Шлях:   Игорь Пидоренко › ЧУЖИЕ ДЕТИ                          │
│ Файл:   Сборники/Сборник «Румбы фантастики»/(1988) Румбы….fb2 │
│ Зміст:  Землей рожденные · Амазония… · Чужие дети · …         │
└ enter відкрити · f у Finder · c копіювати шлях · a за автором · esc вихід ┘
```

- Пошук на кожне натискання з debounce ~50 мс; FTS5 повертає до 500 кандидатів, TUI ранжує їх fuzzy-збігом (`sahilm/fuzzy`) і показує список.
- `●` — диск підключено, `○` — ні; для офлайн-диска `enter`/`f` показують «підключіть диск <назва>».
- `enter` → `open <файл>`; `f` → `open -R <файл>`; `c` → копіювання повного шляху в буфер (`pbcopy`); `a` → замінити запит на автора вибраного твору.

## Обробка помилок

- Кодування: з XML-декларації; підтримуються utf-8, windows-1251, koi8-r (`golang.org/x/text`); невідоме → спроба UTF-8, інакше файл у звіт помилок.
- Битий XML → книга індексується лише за ім'ям файлу, файл у звіт помилок.
- Відсутній індекс при запуску TUI/search → підказка `findbooks add <шлях>`.
- Диск бібліотеки не підключено під час `update` → бібліотека пропускається з попередженням.

## Тестування

- `fb2`: фікстури — UTF-8, cp1251, «Румбы»-подібна збірка (секції-автори), звичайний роман з главами, `.fb2.zip`, битий XML.
- `extract`: табличні тести евристики на деревах секцій.
- `index`: нормалізація (табличні тести), запис/пошук на SQLite у тимчасовому файлі, інкрементальне оновлення.
- `tui`: юніт-тести `Update` моделі; зовнішній вигляд — вручну.
- Ручна перевірка на реальній бібліотеці «Советская фантастика» (час індексації, критерій успіху).
