# findbooks — перегляд тексту твору в TUI

Дата: 2026-09-29. Доповнює `2026-09-29-findbooks-design.md`.

## Мета

Знайшовши твір, користувач хоче швидко переконатися, що це саме той текст, — не запускаючи зовнішню читалку і не гортаючи збірку до потрібного оповідання. Повноцінне читання лишається за звичною програмою (`enter`).

**Критерій успіху:** пошук «чужие дети» → `ctrl+r` → за мить на екрані початок саме цього оповідання всередині збірки, з прокруткою; `enter` звідти відкриває книгу у зовнішній програмі, `esc` повертає до результатів.

## Рішення

| Питання | Рішення |
|---|---|
| Де читати | У TUI, повноекранний перегляд усього тексту твору з прокруткою |
| Формати | FB2 (і `.fb2.zip`), TXT; решта — підказка «enter відкриє у програмі» |
| Як знайти твір у файлі | Повторний розбір файлу; `extract.Works` повертає секцію кожного твору, вибір за `works.ord` |
| Схема індексу | Без змін; текст книг в індекс не пишеться; `extract.Version` не змінюється |
| Диск не підключено | Перегляд недоступний, статус на екрані пошуку |
| Клавіша | `ctrl+r` (`ctrl+p` уже означає «вгору») |
| Перехід між творами збірки | Не робимо (YAGNI) |

## Компоненти

### fb2

```go
type BlockKind int // BlockTitle, BlockSubtitle, BlockPara, BlockPoemLine, BlockEpigraph, BlockCite, BlockEmpty, BlockImage

type Block struct {
	Kind BlockKind
	Text string // пробіли згорнуто
}

// Section отримує поле Blocks []Block — вміст секції в порядку документа,
// без вкладених секцій (вони в Children). Заповнюється лише ParseText.

func ParseText(r io.Reader) (*Book, error)
func ParseTextFile(path string) (*Book, error) // як ParseFile, включно з .fb2.zip
```

- `Parse`/`ParseFile` не змінюють поведінки і не заповнюють `Blocks` — пам'ять під час індексації не росте. Обидва режими — один парсер із прапорцем `withText`.
- Заголовок секції — блок `BlockTitle` (абзаци заголовка — окремі блоки); `<subtitle>` → `BlockSubtitle`; `<p>` → `BlockPara`; рядок `<v>` у `<poem>` → `BlockPoemLine`, межа строфи → `BlockEmpty`; абзаци `<epigraph>` → `BlockEpigraph`, `<cite>` → `BlockCite`, `<text-author>` — у тому ж виді, що й батьківський блок; `<empty-line/>` → `BlockEmpty`.
- `<image>` → `BlockImage` з порожнім `Text`: fb2 не залежить від i18n, підпис «[ілюстрація]» рендерить tui.
- Посилання `<a>` (примітки) — лише їхній текст; `<body name="notes">` і `<binary>` пропускаються, як і зараз.

### extract

```go
type Work struct {
	Title, Author, TreePath string
	Section *fb2.Section // секція твору; nil — твір є вся книга (не збірка)
}
```

Евристика не змінюється, `Version` лишається 2.

### index

`Hit` отримує `WorkOrd int`, `Size, MTime int64` — наявні колонки `works.ord`, `books.size`, `books.mtime` додаються в `searchSQL`.

### preview (новий пакет)

```go
type Doc struct {
	Title, Author string
	Blocks        []fb2.Block
	Stale         bool // файл змінився після індексації або твір знайдено не за ord
}

var ErrUnsupported = errors.New("preview: format not supported")

func Load(absPath string, h index.Hit) (Doc, error)
```

- **FB2:** `fb2.ParseTextFile` → `extract.Works` → твір з індексом `h.WorkOrd`, якщо його назва дорівнює `h.Title`. Інакше — перший твір з такою назвою (`Stale = true`). Не знайдено — уся книга (`Stale = true`). Твір з `Section == nil` — уся книга. Блоки твору — блоки його секції та всіх вкладених, у порядку документа. Розмір або mtime файлу не збігаються з `h.Size`/`h.MTime` → `Stale = true`.
- **TXT:** кодування — UTF-8, якщо байти валідні, інакше windows-1251. Абзаци — за порожніми рядками; рядки всередині абзацу з'єднуються пробілом.
- **Інші формати:** `ErrUnsupported`.

### tui

- `Actions.Preview func(path string, h index.Hit) (preview.Doc, error)`; `DefaultActions` → `preview.Load`. Тести підміняють.
- Новий `screenPreview` на `bubbles/viewport`.
- Пошук: `ctrl+r` на вибраному результаті. Перевірки до завантаження: диск не підключено (`Actions.Root` → false) → статус; файл не існує (`Actions.Exists`) → статус. Інакше — статус «Завантаження…» і асинхронна команда з `previewSeq`; `previewMsg` з іншим `seq` ігнорується. Будь-яка клавіша навігації/`esc` до приходу відповіді збільшує `seq`.
- Помилка `ErrUnsupported` / розбору → статус, екран не перемикається.
- Успіх → `screenPreview`. Текст форматується під ширину `min(width-4, 100)` (перенос за словами, `ansi.Wordwrap`); повторно — на `tea.WindowSizeMsg`.

**Вигляд:**

```
Чужие дети — Николай Пидоренко
Фантастика-72 (1972) › Николай Пидоренко › Чужие дети        [● dsvDev]
──────────────────────────────────────────────────────────────
⚠ Файл змінився після індексації — показано найкращий збіг   (лише коли Stale)
    Текст твору…
──────────────────────────────────────────────────────────────
37% · ↑↓ pgup/pgdn space home/end · enter відкрити · ctrl+o Finder · esc назад
```

Оформлення: `BlockTitle`, `BlockSubtitle` — жирні; `BlockEpigraph`, `BlockCite` — курсив, відступ 4; `BlockPoemLine` — відступ 4, без переносу-злиття рядків; `BlockPara` — червоний рядок 4 пробіли; `BlockEmpty` — порожній рядок; `BlockImage` — тьмяне `[ілюстрація]`. Між абзацами порожніх рядків немає; перед заголовком — один.

**Клавіші екрана перегляду:** `↑`/`↓`, `pgup`/`pgdn`/`space`, `home`/`end` — прокрутка; `enter` — відкрити у програмі; `ctrl+o` — показати у Finder; `ctrl+y` — копіювати шлях; `ctrl+g` — мова; `esc` — назад до результатів (запит, курсор, список не змінюються); `ctrl+c` — вихід. Однолітерних клавіш немає — розкладка не важлива.

### i18n

Нові ключі в обох каталогах: підказка `ctrl+r` у довідці пошуку, довідка екрана перегляду, «Завантаження…», «Диск %s не підключено», «Файл не знайдено: %s», «Перегляд для %s недоступний — enter відкриє у програмі», «Не вдалося прочитати: %s», попередження `Stale`, «[ілюстрація]».

## Обробка помилок

| Ситуація | Поведінка |
|---|---|
| Диск не підключено | Статус «Диск … не підключено», без завантаження |
| Файл зник | Статус «Файл не знайдено: …» |
| PDF, DJVU, EPUB… | Статус «Перегляд для PDF недоступний — enter відкриє у програмі» |
| Помилка розбору / паніка парсера | Статус «Не вдалося прочитати: …» (паніка перехоплюється в `preview.Load`) |
| Файл змінився після індексації | Перегляд відкривається з попередженням |
| Відповідь запізнилась | Ігнорується за `seq` |

## Тестування (TDD)

- **fb2:** `ParseText` — види блоків (абзац, вірш зі строфами, епіграф, цитата, `text-author`, `empty-line`, `image`), вміст приміток і `<binary>` пропускаються, `.fb2.zip`, windows-1251; `Parse` не заповнює `Blocks`; наявні тести зелені.
- **extract:** `Work.Section` вказує на свою секцію, зокрема під секцією-автором; для не-збірки `nil`.
- **preview:** вибір за `ord`; `ord` з іншою назвою → пошук за назвою + `Stale`; не знайдено → уся книга + `Stale`; розмір/mtime відрізняються → `Stale`; TXT UTF-8 і windows-1251; PDF → `ErrUnsupported`.
- **index:** `Search` заповнює `WorkOrd`, `Size`, `MTime`.
- **tui** (фейкові `Backend`/`Actions`): `ctrl+r` → перегляд; `esc` → назад зі збереженим станом; офлайн / нема файлу / непідтримуваний формат → статус без перемикання; застарілий `previewMsg` ігнорується; ресайз переформатовує; `enter`/`ctrl+o`/`ctrl+y` на перегляді викликають відповідні `Actions`.
