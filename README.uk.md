# findbooks

[English](README.md) | Українська

Пошук творів у бібліотеках електронних книг — зокрема всередині збірок, альманахів і антологій.

## Встановлення

```bash
go build -o findbooks ./cmd/findbooks
```

## Використання

```bash
findbooks add '/Volumes/dsvDev/Бібліотека/Советская фантастика'   # зареєструвати й проіндексувати
findbooks                                                          # інтерактивний пошук і керування бібліотеками
findbooks search чужие дети                                        # пошук з командного рядка
findbooks search --author пидоренко --json
findbooks update --all                                             # доіндексувати змінене
findbooks list
findbooks remove 'Советская фантастика'
```

Індекс лежить у `~/.local/share/findbooks/index.db` (інший — `--db <файл>`). Пошук працює і тоді, коли диск з бібліотекою не підключено: такі результати позначені `○`.

## Мова

За замовчуванням інтерфейс англійською. Українську можна вибрати:

- назавжди: `findbooks config lang uk` (повернути англійську — `findbooks config lang en`);
- разово: `findbooks --lang uk …` або змінна середовища `FINDBOOKS_LANG=uk`;
- у TUI: `ctrl+g` перемикає EN ↔ УКР і запам'ятовує вибір.

Пріоритет: `--lang` > `FINDBOOKS_LANG` > збережене налаштування > англійська.

У TUI: `enter` — відкрити, `ctrl+l` — бібліотеки, `ctrl+o` — показати у Finder, `ctrl+y` — копіювати шлях, `tab` — шукати за автором, `ctrl+g` — мова, `↑`/`↓` — вибір, `esc` — вихід.

### Бібліотеки в TUI

Якщо індекс порожній, `findbooks` відкриває екран «Бібліотеки»; з пошуку до нього веде `ctrl+l`.

- `a` — вибрати теку в діалозі Finder і проіндексувати її (прогрес видно на екрані, `esc` — скасувати);
- `u` — оновити вибрану бібліотеку;
- `d` — прибрати бібліотеку з індексу (файли не чіпаються; підтвердження `y`);
- `esc` — назад до пошуку (якщо індекс порожній — вихід).

Клавіші працюють і в українській розкладці (`ф`, `г`, `в`, `н`).

FB2 (і `.fb2.zip`) індексуються разом зі змістом збірок; PDF, DJVU, DOC, DOCX, RTF, TXT, EPUB, MOBI — за ім'ям файлу і текою.
